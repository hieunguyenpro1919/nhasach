# QUY TẮC KHI GHI NHẬN BUG ĐÃ SẢY RA TRONG QUÁ TRÌNH THỰC HIỆN DỰ ÁN
1. mỗi 1 bug đều phải có 1 file tương ứng để ghi nhận đã có bug đó. tên file luôn là BUG_tên_bug_ngày_tháng.md
2. trong file ghi nhận bug phải ghi đầy đủ các thông tin chi tiết.
3. cuối file luôn phải ghi nhận trạng thái là <ĐÃ SỬA><CHƯA SỬA><ĐANG SỬA>
4. nếu cùng một BUG sảy ra, không ghi nhận lại vào file BUG đã soạn mà phải soạn thêm 1 file mới để ghi nhận bug đó.
5. Luôn ghi nhận BUG trong quá trình làm, nếu tự phát hiện hoặc có người test ra đều phải ghi nhận trước.

## CẤM
- tự tiện sửa file BUG đã được tạo ra. nếu cần chỉnh sửa phải ghi nhận thêm 1 file BUG mới để chỉnh sửa file BUG cũ và ghi nhận trạng thái của file cũ là <ĐÃ SỬA>

## LƯU Ý 
- nếu 1 BUG xuất hiện quá nhiều lần khi ghi nhận bug thì phải soạn 1 file <CẢNH BÁO KHẨN> để ưu tiên giải quyết dứt điểm.
